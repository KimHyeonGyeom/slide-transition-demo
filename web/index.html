슬라이드 영상 전환 테스트

이미 만들어 둔 슬라이드 영상(음성 포함)에 "들어올 때 전환"을 붙입니다. 영상의 처음 T초가 앞 슬라이드 이미지에서 이 영상으로 바뀌는 전환이 되고, 해상도, fps, 프레임 수, 길이, 음성은 원본과 똑같이 유지됩니다. 첫 슬라이드는 검정(또는 흰색) 화면에서 들어옵니다.
API 서버 확인 중...

영상 개수와 같거나 하나 적게 올립니다. 이미지가 없는 슬라이드의 다음 슬라이드에는 전환을 넣을 수 없습니다.
